# Локальный AI (Ollama)

RestoPro не включает облачную языковую модель и **не даёт свободный чат**. Раздел «AI» считает по цифрам контура (продажи, смены, склад, средний чек, пики) и либо просит **вашу** Ollama кратко прокомментировать уже посчитанное, либо показывает эвристику. Эвристика всегда подписана как эвристика.

## Что делает модель

Только рабочие задачи:

- сводка периода
- рекомендации (плюс локальные сигналы контура)
- маржа / фудкост / списания
- прогноз месяца против плана
- пиковые часы и средний чек для постановки смены
- покрытие склада и блюда класса A

Те же кнопки стоят на **Аналитике** (план-факт, покрытие, ABC) и **Отчётах** (средний чек / пик). Свободного чата нет.

Цифры считает сервер. Модель не должна выдумывать суммы.

## Что задать в приложении

Настройки → Сеть → «Локальный AI (Ollama)»:

1. Включить Ollama.
2. Базовый URL без хвоста `/v1`.
3. Имя модели, как в `ollama list` (часто `llama3.2`, `qwen2.5`, `mistral`).

Сохранение пишет адрес в снимок сети (Neon). Env `OLLAMA_BASE_URL` / `OLLAMA_MODEL` — запасной путь для своего сервера, если в настройках выключатель не выключен.

## Локально, рядом с `npm run dev`

```bash
ollama serve
ollama pull llama3.2
```

В настройках сети: `http://127.0.0.1:11434`, модель `llama3.2`. Dev-сервер и Ollama на одной машине — этого достаточно. Запросы идут **с сервера** приложения, не из браузера, поэтому CORS для Ollama не нужен.

Проверка: `curl http://127.0.0.1:11434/api/tags`.

## Сайт на Vercel, Ollama в кафе

`https://restopro.vercel.app` не достучится до `127.0.0.1` кухни. Нужен **публичный HTTPS до машины с Ollama**:

- Cloudflare Tunnel (`cloudflared`) на `11434`
- Tailscale Funnel
- ngrok / аналоги

В настройках сети укажите URL туннеля (`https://ollama.your-tunnel.example`). Туннель должен проксировать HTTP Ollama как есть (`/api/tags` и `/v1/chat/completions`).

CORS по-прежнему не нужен: Vercel Function ходит на туннель сервером. Если кто-то откроет Ollama прямо из браузера — тогда да, `OLLAMA_ORIGINS`, но RestoPro так не делает.

Firewall: пускайте только туннель, не весь интернет на 11434.

## Если модель не отвечает

Раздел AI пишет, что Ollama недоступна, и показывает эвристику по формулам. Это штатный fallback, не «тихий успех».

Облачный LLM (xAI / OpenAI) в этот контур не подключён.
